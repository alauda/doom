# runtime

React components and hooks for the Doom documentation site. Exported as `@alauda/doom/runtime`.

## STRUCTURE

```
├── components/           # React components for docs rendering
│   ├── _K8sAPIEndpoints.tsx  # K8s API endpoints tables (577 lines — hotspot)
│   ├── OpenAPIPath.tsx       # OpenAPI path details with recursive schema resolution (359 lines — hotspot)
│   └── ...                   # Additional components (Mermaid, ExternalSite, etc.)
├── hooks/                # React hooks for docs features
├── index.ts              # Public entry: re-exports components and hooks
├── translation.ts        # i18n translation utilities
└── utils.ts              # Runtime utility functions
```

## WHERE TO LOOK

| Task                  | File(s)                               |
| --------------------- | ------------------------------------- |
| Add runtime component | `components/`, export from `index.ts` |
| Add React hook        | `hooks/`, export from `index.ts`      |
| Fix K8s API rendering | `components/_K8sAPIEndpoints.tsx`     |
| Fix OpenAPI rendering | `components/OpenAPIPath.tsx`          |
| Change translations   | `translation.ts`                      |

## NOTES

- Components render in browser (client-side React) — not Node.js
- K8s and OpenAPI components consume data from virtual modules generated by plugins
- `_K8sAPIEndpoints.tsx` and `OpenAPIPath.tsx` are complexity hotspots — recursive rendering, many conditional branches
- Components are registered as MDX global components via the `global` plugin
