```yaml
apiVersion: v1

  endpoint: <base64-encoded-endpoint>
kind: Secret
metadata:
  name: <auth-secret-name>
  namespace: cpaas-system
type: Opaque
```

:::

| 参数           | 描述                                                                                                                                                                |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| .data.authUser | DCS 平台 API 用户登录名（base64 编码）                                                                                                                              |
| .data.authKey  | DCS 平台 API 用户登录密码（base64 编码）                                                                                                                            |
| .data.endpoint | 带有 http 或 https 协议的 DCS 平台 API 地址（base64 编码）。**注意**：DCS 平台的默认 API 端口为 7443（不是常见的 8443）。如果你的环境使用自定义端口，请咨询管理员。 |
