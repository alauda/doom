# 安装

本节概述了安装管理集群的具体步骤。以下操作遵循“准备 → 执行 → 验证”模型，关键参数说明已在 UI 配置中详细列出。

## 步骤 1：下载安装包

**准备**

- 登录 **Customer Portal** 获取最新的安装包和签名文件。
- 如果您尚未注册账号，请联系技术支持。

**执行**

- 下载完成后，使用 GPG 工具验证安装包的完整性。
- 请根据您的操作系统安装 GPG 工具（参考下面的命令）。

  ```bash
  # Ubuntu
  sudo apt-get install gnupg
  # CentOS
  yum install gnupg
  # Mac
  brew install gpg
  ```

**验证**
按以下步骤进行验证：

### 1.1 下载并验证公钥

```bash
curl -O https://www.alauda.cn/download/verify-key.pub
md5sum verify-key.pub
```

- 输出的 MD5 值应为：`2eaddfab97d2951a8915f327acb53562`。

### 1.2 导入公钥并验证指纹

```bash
gpg --import verify-key.pub
gpg --fingerprint BB097AE6
```

- 指纹应完全匹配：
  ```
  09EE E7B9 A30C F4B3 5E31 A91B 2704 1C16 BB09 7AE6
  ```

### 1.3 验证安装包签名

```bash
gpg --verify <signature file> <installation package>
```

例如：

```bash
gpg --verify cpaas-devops-2.14.0.tgz.sig cpaas-devops-2.14.0.tgz
```

- 正常输出应显示 “Good signature” 信息。

## 步骤 2：将安装包上传到控制节点

**准备**

- 确保目标控制节点可通过网络访问，并且具有足够的存储空间（解压后至少 100GB）。

**执行**

- 将安装包上传到控制节点上建议的目录 `/root/cpaas-install`，并将其解压：

  ```shell
  tar -xvf {path_to_installation_package}/{installation_package_name} -C /root/cpaas-install
  cd /root/cpaas-install/installer || exit 1
  ```

**验证**

- 检查解压后的目录结构是否完整。

---

## 步骤 3：启动安装程序

**准备**

- 确保控制节点可通过网络访问，并且 PC 可以访问其 IP。
- 检查依赖是否已按照先决条件完成配置。

**执行**

- 默认启动安装程序（使用 Kube-OVN 网络插件）：

  ```bash
  bash setup.sh
  ```

- 如需使用 Calico 网络插件，请执行：

  ```bash
  bash setup.sh --network-mode calico
  ```

- 如需指定 IPv6 或双栈模式，可以添加参数 `--ip-family ipv6` 或 `--ip-family dual`。

**验证**

- 启动安装程序后，命令行终端将输出 Web UI 访问地址；请等待约 5 分钟后在 PC 上访问该页面，确认其可正常加载。

## 步骤 4：安装管理集群（配置 UI 参数）

**准备**
在 Web UI 中，按照提示配置安装管理集群的关键参数，具体如下：

- **Kubernetes 版本**
  - 所有可选版本均已经过严格测试。
  - 建议选择最新版本，以获得最佳功能和支持。

- **集群网络协议**
  - 支持 IPv4 单栈、IPv6 单栈以及 IPv4/IPv6 双栈。
  - 注意：选择双栈模式时，所有节点都必须正确配置 IPv6 地址；网络协议一旦配置后无法更改。

- **集群地址**
  - 输入已准备好的 `global VIP`，用于对外访问 kube-apiserver。
  - 如果已配置 LoadBalancer，请填写其 VIP 地址并关闭“自建 VIP”；否则，启用“自建 VIP”并输入所需的 VIP，安装程序将自动部署 keepalived。

- **平台访问地址**
  - 输入已准备好的 `External IP` 或域名。
  - 默认启用 HTTPS 访问；如需 HTTP，请在高级设置中启用。
  - 支持多地址配置：您可以填写内网地址，并在“其他设置 > 其他平台访问地址”中添加外网地址。

- **证书**
  - 默认使用自签名证书以支持 HTTPS。
  - 如需自定义证书，请上传已有证书。

- **镜像仓库**
  - 默认使用平台部署的镜像仓库，其中包含所有组件镜像。
  - 如需使用外部镜像仓库，请联系技术支持获取镜像同步方案进行配置。

- **容器网络**
  - 管理集群的默认子网和 Service 范围不得重叠。
  - 使用 Kube-OVN Overlay 网络时，请确保容器网络与主机网络不在同一子网中，以避免网络异常。

- **节点名称**
  - 如果选择“使用主机名作为节点名称”，请确保所有节点主机名唯一。

- **Global 集群平台节点隔离**
  - 当计划在管理集群上运行工作负载时，请启用此项。
  - 启用后，可以将节点设置为“平台专用”，此类节点将仅运行平台组件；DaemonSet 类型除外。

- **添加节点**
  - **控制节点**：
    - 可以添加 1 个或 3 个控制节点（3 个用于高可用配置）。
    - 如果启用了“平台专用”，请关闭“可部署应用”，此时控制节点将仅运行平台组件；否则，您可以选择是否启用“可部署应用”。
  - **计算节点**：
    - 如果启用了“平台专用”，请关闭“可部署应用”；否则，必须启用该项。
  - 使用 Kube-OVN 时，您可以通过输入网关名称来指定节点网卡。
  - 如果节点可用性检查失败，请按照页面提示进行调整后重新添加。

**执行**

- 按照 Web UI 提示填写配置参数，然后启动安装向导进行安装。

**验证**

- 安装完成后，页面将显示平台访问地址和安装状态；如果存在错误，请根据提示进行调整。

## 步骤 5：验证安装是否成功

**准备**

- 登录平台 Web UI 并确认管理集群状态。

**执行**

- 在“平台管理”视图中，单击“集群管理 > 集群”，找到名为 `global` 的集群；
- 从右侧下拉菜单中选择“CLI 工具”，并执行以下命令检查状态：

  ```shell
  # Check for any failed Charts
  kubectl get apprelease --all-namespaces
  # Check for any failed Pods
  kubectl get pod --all-namespaces | awk '{if ($4 != "Running" && $4 != "Completed")print}' | awk -F'[/ ]+' '{if ($3 != $4)print}'
  ```

**验证**

- 确认输出结果中不包含异常或失败信息。
- 如有异常，请参考故障排查指南进行处理。

**浏览器兼容性说明**
建议使用以下浏览器访问平台：

- **Google Chrome**：93 及以上版本
- **Firefox**：92 及以上版本
