# 安装概览

平台架构和关键特性如下：

- **架构设计**
  - **管理集群**：负责平台的核心管理，提供集群、租户管理和全局调度。管理集群安装完成后，可按需添加或创建业务集群。
  - **业务集群**：专为承载业务工作负载而设计，并支持横向扩展。业务集群可独立部署，也可通过满足版本要求的现有集群接入。

- **设计原则**
  1. **控制平面隔离部署**
     安装管理集群时，必须使用专用物理资源，且不与业务集群共享，以确保控制平面的稳定性和安全性。
  2. **混合部署兼容性**
     在开发测试环境或资源受限场景下，允许在管理集群（即 global 集群）上同时运行业务工作负载，实现管理与业务功能共置。
  3. **标准化接入规范**
     支持两种接入业务集群的方式：
     - 新建业务集群（推荐）
     - 连接满足版本要求的现有集群（需预检）
